- Fresh /proc and /dev mounts were required for Bun subprocess spawning in bwrap. Without them, even Bun spawning /bin/true or /usr/bin/getent failed with EACCES, despite direct getent working. Adding --proc /proc --dev /dev fixed it. This was an environment papercut, not a Silo lifecycle failure.
- Binding a nonexistent /usr/local/bin/k3d beneath a read-only root failed; binding the supplied existing bin directory at /tmp/bin fixed it without system edits.
- A hosts table containing only TILT_HOST refused with the clear error “hosts must include APP_HOST.” Adding the documented APP_HOST template fixed the fixture.
- One closeout shell command used zsh's reserved status variable and stopped; renaming the loop variable let the closeout checks run. No product behavior depended on that failed shell command.
